# Sejarah VUR

## Latar Belakang

Void Linux dikenal ringan, bersih, dan cepat. Namun seperti banyak distro minimalis lainnya, tidak semua software tersedia di repositori resmi. Ini memunculkan pertanyaan yang wajar: bagaimana pengguna bisa mendapatkan paket tambahan tanpa harus menunggu masuk ke repositori resmi? Bagaimana komunitas bisa berkontribusi?

Dari kebutuhan itu, lahirlah ide VUR.

## Inspirasi dari AUR

Arch Linux memiliki **AUR (Arch User Repository)** — repositori komunitas yang memungkinkan pengguna berbagi PKGBUILD dan membangun paket secara lokal. Konsepnya sederhana: komunitas yang membuat, membangun, dan berbagi.

T4n OS mengadaptasi filosofi itu ke ekosistem Void Linux, dengan `xbps-src` sebagai fondasi build system-nya. Hasilnya adalah **VUR — Void User Repository**.

## Peran VUR dalam T4n OS

Secara teknis, VUR berisi template paket, build script, dan metadata. Namun dampaknya lebih luas dari itu — VUR memberi T4n OS identitas dan ekosistem sendiri, tidak lagi sepenuhnya bergantung pada repositori resmi Void Linux.

## Status Saat Ini

VUR masih dalam pengembangan aktif. Kontribusi komunitas terbuka dan sambutan.
