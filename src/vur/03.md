# Struktur VUR

## Direktori

```
vur/
├── core/                     # Paket inti , umum digunakan
│   └── <nama-paket>/
├── extra/                    # Paket tambahan
│   └── <nama-paket>/
├── multilib/                 # Paket 32-bit untuk sistem x86_64
│   └── <nama-paket>/
├── vtools/                   # Tools internal VUR
│   ├── generate.sh           # Generate metadata index
│   └── scan.sh               # Scan paket di direktori
├── vdokumentasi/             # Dokumentasi VUR
│   ├── index.md
│   ├── template/
│   │   └── a.md              # Panduan penulisan template
│   ├── build-style/          # Dokumentasi build style
│   └── 3NGLISH/              # Dokumentasi bahasa Inggris
│       ├── index.md
│       ├── template/
│       └── build-style/
├── ISSUES/
│   └── ISSUES1.md
├── .github/
│   └── workflows/
│       └── index.yml

├── index.json                # Indeks semua paket
├── packages.json             # Metadata lengkap paket
├── categories.json           # Daftar kategori paket
├── search.json               # Data untuk pencarian
├── README.md
├── README-EN.md
└── LICENSE
```

## Kategori Paket

| Kategori   | Isi                                              |
|------------|--------------------------------------------------|
| `core`     | Paket inti — stabil dan umum digunakan           |
| `extra`    | Paket tambahan — bisa bersifat eksperimental     |
| `multilib` | Paket 32-bit untuk sistem x86_64 glibc           |

## File Index

| File              | Fungsi                                      |
|-------------------|---------------------------------------------|
| `index.json`      | Indeks semua paket yang tersedia di VUR     |
| `packages.json`   | Metadata lengkap setiap paket               |
| `categories.json` | Daftar kategori yang tersedia               |
| `search.json`     | Data yang digunakan Let-X untuk pencarian   |

## vtools

| Script         | Fungsi                                         |
|----------------|------------------------------------------------|
| `generate.sh`  | Generate ulang file metadata index             |
| `scan.sh`      | Scan paket di seluruh direktori kategori       |
