# Firmware

T4n OS menyediakan sejumlah paket firmware melalui repositorinya. Beberapa paket hanya tersedia setelah repositori [nonfree](../04/repository/04.md) diaktifkan.

## 1. Microcode

Microcode dimuat ke CPU atau GPU saat booting oleh BIOS, namun dapat diperbarui kemudian oleh sistem operasi. Pembaruan microcode memungkinkan perilaku CPU atau GPU dimodifikasi untuk mengatasi bug tertentu — tanpa perlu mengganti hardware.

### Intel

Instal paket microcode Intel:

```bash
sudo xbps-install -S intel-ucode
```

> **Catatan:** Paket ini berada di repositori **nonfree**. Pastikan repositori tersebut sudah [diaktifkan](#) sebelum melanjutkan.

Setelah instalasi, regenerasi [initramfs](./09.md) secara manual:

```bash
sudo xbps-reconfigure -f linux<versi>
```

Pada pembaruan berikutnya, microcode akan ditambahkan ke initramfs secara otomatis.

### AMD

Instal paket firmware AMD:

```bash
sudo xbps-install -S linux-firmware-amd
```

Paket ini mencakup microcode untuk CPU maupun GPU AMD. Microcode akan dimuat secara otomatis — tidak ada konfigurasi tambahan yang diperlukan.

## 2. Verifikasi

Untuk memverifikasi bahwa microcode berhasil dimuat, periksa informasi pada `/proc/cpuinfo`:

```bash
grep microcode /proc/cpuinfo
```

## 3. Menghapus Firmware

Secara default, paket `linuxX.Y` dan `base-system` menginstal sejumlah paket firmware. Firmware yang tidak terpakai tidak wajib dihapus, namun jika diperlukan, ikuti langkah berikut:

1. Konfigurasi XBPS untuk [mengabaikan](../04/02.md) paket firmware yang tidak diinginkan.
2. Hapus paket tersebut dengan perintah:

```bash
sudo xbps-remove -R <nama-paket-firmware>
```
