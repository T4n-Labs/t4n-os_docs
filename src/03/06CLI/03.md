# Server

Setelah [Base](./02.md) dijelaskan, halaman ini membahas aplikasi dan layanan sisi server untuk **T4n OS**.

## 1. Ruang Lingkup Server

Halaman ini mencakup perangkat lunak yang umum dipasang pada sistem server:

- Web server (nginx, Apache)
- Database (PostgreSQL, MariaDB)
- SSH dan akses remote
- Monitoring dan logging

## 2. Instalasi Dasar

Pasang paket yang dibutuhkan dengan `xbps-install`:

```bash
xbps-install -S nginx
```

| Parameter | Keterangan |
| --- | --- |
| -S | Sinkronisasi index repository sebelum memasang |
| nginx | Nama paket web server |

## Tips Tambahan

- Aktifkan service dengan `ln -s /etc/sv/<service> /var/service/`
- Pastikan firewall dikonfigurasi sebelum mengekspos service ke jaringan
