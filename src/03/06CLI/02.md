# Server

T4n OS dapat digunakan sebagai sistem operasi server berkat fondasi Void Linux yang ringan, cepat booting, dan bebas dari systemd. Kombinasi runit sebagai init system dan XBPS sebagai package manager menjadikannya pilihan solid untuk server minimalis maupun production.

## Mengapa T4n OS untuk Server?

- **Ringan** — Tidak ada layanan yang berjalan di latar belakang kecuali yang diaktifkan secara eksplisit.
- **Deterministik** — runit memastikan setiap layanan selalu dijalankan dengan environment yang bersih dan konsisten.
- **Mudah diaudit** — Codebase runit kecil, service directory berbasis filesystem, mudah dilacak dan dikontrol.
- **Rolling release** — Paket selalu up-to-date tanpa perlu upgrade versi OS.

## Konsep Dasar: runit untuk Service Server

Semua layanan server dikelola melalui runit. Setiap layanan memiliki **service directory** di `/etc/sv/` yang berisi script `run` untuk menjalankan proses di foreground.

### Mengaktifkan Layanan

```bash
ln -s /etc/sv/<layanan> /var/service/
```

Layanan yang di-link akan otomatis berjalan saat boot dan restart jika berhenti.

### Contoh Layanan Server Umum

| Layanan       | Paket          | Service Directory       |
|---------------|----------------|-------------------------|
| Web server    | `nginx`        | `/etc/sv/nginx`         |
| Database      | `postgresql`   | `/etc/sv/postgresql`    |
| SSH daemon    | `openssh`      | `/etc/sv/sshd`          |
| DNS resolver  | `unbound`      | `/etc/sv/unbound`       |
| Mail server   | `postfix`      | `/etc/sv/postfix`       |
| Reverse proxy | `caddy`        | `/etc/sv/caddy`         |

### Cek Status Semua Layanan Aktif

```bash
sv status /var/service/*
```

## Logging

T4n OS tidak menginstal syslog daemon secara default. Untuk server, disarankan menggunakan `socklog`:

```bash
sudo xbps-install -S socklog-void
ln -s /etc/sv/socklog-unix /var/service/
ln -s /etc/sv/nanoklogd    /var/service/
```

Log tersimpan di `/var/log/socklog/` dan dapat dibaca dengan `svlogtail`.

## Firewall

Untuk mengamankan server, aktifkan firewall dengan `nftables` atau `iptables`. Lihat [dokumentasi Firewall](../NETWORK/firewall.md) untuk panduan lengkap.
