# Cosmic DE

T4n OS Cosmic DE adalah varian Desktop Environment Wayland Modern yang dibangun menggunakan `Rust`.

`COSMIC DE` (singkatan dari Computer Operating System Main Interface Components Desktop Environment) adalah lingkungan desktop (desktop environment) sekaligus Wayland compositor sumber terbuka untuk Linux yang dikembangkan oleh System76.
