# Security

Setelah [konfigurasi dasar](../01.md) selesai, penting untuk memahami aspek keamanan sistem **T4n OS**.

## 1. Ruang Lingkup Security

- [AppArmor](./02.md) — Mandatory Access Control berbasis profil

## 2. Prinsip Dasar

Keamanan **T4n OS** (berbasis Void Linux) mengandalkan:

- Sistem minimal tanpa komponen yang tidak perlu
- Kontrol penuh pengguna atas service dan paket
- AppArmor untuk pembatasan akses aplikasi

## Tips Tambahan

- Aktifkan hanya service yang benar-benar dibutuhkan
- Perbarui sistem secara berkala dengan `xbps-install -Su`
