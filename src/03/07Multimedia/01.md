# Multimedia

## Pengaturan Audio

T4n OS mendukung beberapa pilihan sistem audio. Pilih salah satu sesuai kebutuhan:

| Sistem         | Keterangan                                                                 |
|----------------|----------------------------------------------------------------------------|
| **PipeWire**   | Pilihan modern — pengganti langsung PulseAudio, mendukung audio dan video  |
| **PulseAudio** | Dibutuhkan oleh beberapa aplikasi proprietary                              |
| **ALSA**       | Lapisan audio dasar kernel Linux, tanpa daemon tambahan                    |

> Jika `elogind` tidak aktif, pastikan user tergabung di grup `audio` agar dapat mengakses perangkat audio.
