# Let-X

`letx` adalah CLI tool untuk Void Linux yang memudahkan pencarian, pengelolaan, dan pengunduhan template paket dari **VUR (Void User Repository)** — konsep serupa AUR Helper di Arch Linux.

| Info    | Detail                                    |
|---------|-------------------------------------------|
| Binary  | `letx`                                    |
| Versi   | 0.1.2                                     |
| Bahasa  | Python 3.11+                              |
| Repo    | https://github.com/T4n-Labs/Let-X         |

## Instalasi

Via script otomatis:

```bash
git clone https://github.com/T4n-Labs/Let-X
cd Let-X
sudo ./install.sh
```

Via `xbps-src` (jika sudah setup `void-packages`):

```bash
cp -r xbps-template/letx ~/void-packages/srcpkgs/letx
cd ~/void-packages
./xbps-src pkg letx
sudo xbps-install --repository=path/to/hostdir/binpkgs letx
```

## Penggunaan

```bash
letx <subcommand> [OPSI] [ARGUMEN]
```

| Subcommand  | Fungsi                                              |
|-------------|-----------------------------------------------------|
| `search`    | Cari paket di VUR berdasarkan nama atau deskripsi   |
| `info`      | Tampilkan detail paket dan status lokal             |
| `list`      | Tampilkan daftar paket per kategori                 |
| `get`       | Unduh template paket ke lokal                       |
| `update`    | Perbarui cache index VUR                            |

## Contoh Penggunaan

Update cache index VUR:

```bash
letx update
```

Cari paket:

```bash
letx search godot
```

Lihat detail paket:

```bash
letx info godot
```

Unduh template paket:

```bash
letx get godot
```

Setelah template diunduh, build dan install :

```bash
letx -x pkg <name_package>
sudo xbps-install --repository=path/to/hostdir/binpkgs <name_package>
```

## Catatan Penting

- Let-X hanya mengunduh dan mengelola **template** — proses build tetap dilakukan oleh `xbps-src`.
- VUR tidak diaudit seketat repositori resmi Void. Selalu review file `template` dan `patches/` sebelum build.
- Membutuhkan `void-packages` yang sudah di-bootstrap untuk build paket.
