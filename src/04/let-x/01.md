# Let-X

`letx` adalah CLI tool untuk Void Linux yang memudahkan pencarian, pengelolaan, dan pengunduhan template paket dari **VUR (Void User Repository)** — konsep serupa AUR Helper di Arch Linux.

| Info    | Detail                                    |
|---------|-------------------------------------------|
| Binary  | `letx`                                    |
| Versi   | 1.0.0                                     |
| Bahasa  | Python 3.10+                              |
| Repo    | https://github.com/gh0st4n/Let-X          |

## 1. Instalasi Manual
Metode instalasinya memiliki 2 metode :

1. uv(Package Manager Python) — Recommended
```bash
git clone https://github.com/gh0st4n/Let-X
cd Let-X

# Install menggunakan uv (Global/Tool)
uv tool install .

# Atau, untuk instalasi mode pengembangan (editable)
uv pip install -e .
```

2. Via script otomatis:

```bash
git clone https://github.com/T4n-Labs/Let-X
cd Let-X
chmod +x setup.sh

# Untuk instalasi sistem-wide (memerlukan sudo)
sudo ./setup.sh --install

# Untuk instalasi user-only (tanpa sudo)
./setup.sh --install user
```

Via `xbps-src` (jika sudah setup `void-packages`):

```bash
cp -r xbps-template/letx ~/void-packages/srcpkgs/letx
cd ~/void-packages
./xbps-src pkg letx
sudo xbps-install --repository=path/to/hostdir/binpkgs letx
```

## 2. Penggunaan

```bash
letx <subcommand> [OPSI] [ARGUMEN]
```

| subcommand              | Fungsi                                             |
|-------------------------|----------------------------------------------------|
| `letx update`           | Perbarui database index VUR                        |
| `letx search <pkgname>` | Cari paket di VUR berdasarkan nama atau deskripsi  |
| `letx get <pkgname>`    | Unduh template paket ke lokal                      |
| `letx update <pkgname>` | Unduh template paket ke lokal                      |
| `letx info <pkgname>`   | Tampilkan detail paket dan status lokal            |

## 3. Contoh Penggunaan

Update database index VUR:

```bash
letx update
```

Cari paket:

```bash
letx search discord
```

Lihat detail paket:

```bash
letx info discord
```

Unduh template paket:

```bash
letx get discord
```

update versi template :
```bash
letx update discord
```

## 4. Catatan Penting

- Let-X hanya mengunduh dan mengelola **template** — proses build tetap dilakukan oleh `xbps-src`.
- VUR tidak diaudit seketat repositori resmi Void. Selalu review file `template` dan `patches/` sebelum build.
- Membutuhkan `void-packages` yang sudah di-bootstrap untuk build paket.
